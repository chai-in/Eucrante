Purpose-built

A focused Mac app, not a web service.

Every stage—from preview to processing to import—runs on your Mac.

01

One-click output policies

Four clear choices cover high-quality and storage-balanced music and video. Previewed codec, resolution, bitrate, and estimated size remove guesswork.

02

Rich Apple Music import

Import verified audio with title, artist, album, year, artwork, and optional manual overrides. Artwork is normalized for Music compatibility.

03

Beyond H.264

Preserve compatible H.264 sources and convert high-resolution VP9 to Apple HEVC using VideoToolbox, copying compatible audio without another lossy pass.

04

Private provider sessions

Optional YouTube sign-in stays in Eucrante’s private WebKit store. The app never reads Safari, Brave, Chrome, Firefox, or your password database.

05

Visible progress and recovery

Concrete phases, progress, cancellation, queue history, retry, and verified outputs keep long saves understandable and recoverable.

06

Hardened local tools

Exact helper versions and hashes are pinned. FFmpeg is a restricted LGPL build; every executable is checked and signed inside the final app bundle.

Install today

Build Eucrante from source.

The maintainer currently has a free Apple developer account, so Eucrante does not distribute an unsigned binary that asks people to weaken Gatekeeper.

Terminal
git clone https://github.com/chai-in/Eucrante.git
cd Eucrante
make check
make app
open dist/Eucrante.app
Requirements macOS 14 or newer, full Xcode, Swift 6
DMG-ready release flow A polished drag-to-Applications DMG pipeline is built and tested locally. Public DMGs remain disabled until Developer ID signing and notarization are available.
Use responsibly Save only media you own or are authorized to download.
